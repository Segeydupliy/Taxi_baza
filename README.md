# TaxiBaza.sk

Код сайту taxibaza.sk (WordPress): тема `taxi-rental`, плагін `taxi-rental-core`, плагін флотилій `taxibaza-fleets`.

## Правила роботи
- `main` завжди відповідає тому, що зараз стоїть на живому сайті.
- Кожна нова сторінка чи логіка — окрема гілка і Pull Request з описом: що змінено, які файли, що перевірити.
- У PR не чіпаємо тему й `taxi-rental-core`, окрім узгоджених точок підключення.
- У репозиторій не потрапляють `wp-config.php`, `uploads`, бекапи й дамп бази (див. `.gitignore`).
- Версії плагіна позначаємо тегами для швидкого відкату.

## Структура
- `wp-content/themes/taxi-rental/` — тема (довідкова копія з живого сайту)
- `wp-content/plugins/taxi-rental-core/` — ядро (довідкова копія з живого сайту)
- `wp-content/plugins/taxibaza-fleets/` — плагін флотилій (наш код)
- `prototypes/` — статична верстка до перенесення в шаблони
