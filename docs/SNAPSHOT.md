# Знімок живого сайту

- Дата: 2026-11-05, Duplicator-пакет без бази даних.
- Що всередині: `wp-content/themes/taxi-rental/` (без `assets/img/`) і `wp-content/plugins/taxi-rental-core/` — точна копія з taxibaza.sk.
- Чого немає: WordPress core, uploads, інші плагіни, `wp-config.php`, база даних, картинки теми.
- `main` = те, що стоїть на живому сайті. Зміни до цих файлів — лише через гілку і PR.

## Знахідки під час знімка
- `wp-content/debug.log` ≈ 2 ГБ — на живому сайті ввімкнений запис логу помилок.
- У корені сайту 4 PHP-файли з випадковими назвами (`63GHh8…php`, `Ac2EBc…php`, `YgCb8X…php`, `zms1m7…php`) — залишки інсталятора Softaculous, лише виводять шлях до папки. Не шкідливі, але варто видалити.
- `wp-content/CLAUDE.md` і `STATUS.md` попереднього розробника лежать у публічній папці сайту — копії тут, у `docs/legacy/`.
