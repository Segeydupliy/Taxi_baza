# План: флотилії (реєстрація, профіль, модерація)

Основа — код живого сайту в `main` (знімок 2026-11-05). Макет: Figma «Flotilla» (848:14522).

## Що є в коді зараз
- Роль `fleet` існує (ті самі права, що в `car_owner`). Реєстрація **завжди** створює `car_owner` (`class-account.php`, `tb_account_type` ігнорується).
- **Будь-який власник може сам стати флотилією** у формі профілю кабінету (`tab-profile.php` select `account_type` → `Profile::update_profile` → `set_role`). Без перевірок.
- Модерації профілів немає взагалі. Модерація є лише для оголошень (статуси `pending/publish/rejected/archived`).
- Сповіщень на сайті немає: дзвіночок у шапці — порожнє посилання. Є лише email (`Notifications::render`, шаблони в «Email Templates»).
- Вкладки `/panel/` і кабінету — жорсткі масиви, хуків/фільтрів у темі та ядрі немає жодного.
- Блокування користувача (`tb_user_blocked`) блокує вхід, але не ховає його оголошення.

## Архітектура
Окремий плагін `taxibaza-fleets`. Ядро й тему не переписуємо — лише додаємо кілька `apply_filters` у місцях, де без них не обійтись.

| Що | Як |
|---|---|
| Статус профілю | user meta `tbf_status`: `draft` → `pending` → `approved` / `rejected` / `blocked` |
| Дані профілю | `tbf_profile_live` (бачать водії) і `tbf_profile_draft` (на модерації). Після схвалення draft → live |
| Приховування авто | `pre_get_posts`: `author__not_in` = флотилії не `approved` або `blocked` (кеш в option). Сторінка авто прихованої флотилії → 404. Кабінет і `/panel/` не фільтруються |
| Заблокований кабінет | поки профіль не заповнено: кнопки «Додати оголошення» вимкнені, AJAX `tb_submit_listing` відхиляється |
| Сповіщення (дзвіночок) | власна таблиця `{prefix}tbf_notifications` + AJAX + JS на `.tb-header__bell` |
| Email | `Notifications::render('fleet_*')` + шаблони у «Email Templates» |
| Адмін | вкладка «Флотилії» в `/panel/`: список, перегляд, редагування, оголошення флотилії, Схвалити / Відхилити / Блокувати |

## Мінімальні правки теми/ядра (лише додавання фільтрів)
1. `page-front-admin.php` — фільтри на список вкладок, пункти меню і шлях до шаблону вкладки.
2. `page-dashboard.php` — фільтр на вкладки кабінету (вкладка «Мій профіль» флотилії).
3. `page-login.php` — вибір типу акаунта у формі реєстрації (макет 1.1/1.2).
4. `tab-profile.php` / `class-profile.php` — самостійне перемикання на `fleet` має йти через модерацію, а не одразу.

## Знайдені баги (не стосуються флотилій, виправимо окремо за згодою)
- Причина відхилення оголошення ніколи не потрапляє в email: пишеться `_rejection_reason`, читається `rejection_reason` (`class-notifications.php:151`).
- Посилання «редагувати» в листі про відхилення використовує `listing_id`, а сторінка чекає `post_id`.
- Дві ACF-групи з однаковим ключем (`group_user_profile.json` і `group_tb_user_profile.json`).
- Кабінет пише `phone`/`about`, а `/panel/` читає `phone_number`/`description` — дані не збігаються.
- `wp-content/debug.log` ≈ 2 ГБ.
