# TaxiBaza Fleets

Плагін флотилій для taxibaza.sk. Працює поверх `taxi-rental-core`, не змінюючи його даних.

## Етап 1 (ця версія)
- **Статус профілю флотилії** — user meta `tbf_status`: `draft → pending → approved / rejected / blocked`. Хук `tbf_status_changed( $user_id, $to, $from )`.
- **Перехід у флотилію через модерацію.** Коли власник обирає «Флотилія» в профілі кабінету (або адмін змінює роль), акаунт отримує `draft`. Вихід з ролі `fleet` очищає статус.
- **Приховування авто.** Оголошення флотилій зі статусом не `approved` не показуються в каталозі, містах, AJAX-фільтрах, на головній і в «схожих». Сторінка такого авто — 404 для всіх, крім автора й адміна. Статуси самих оголошень не змінюються.
- **Блокування кабінету.** У статусах `draft`, `rejected`, `blocked` флотилія не може подати оголошення (AJAX `tb_submit_listing` → 403, сторінка додавання → перенаправлення в профіль, кнопки вимкнені).
- **Активація безпечна.** Наявні флотилії отримують `approved`, тож з каталогу нічого не зникає.

Не чіпає: wp-admin, `/panel/`, «Мої оголошення» в кабінеті.
